**About the project**

I am developing a computational pipeline for DNA-based facial approximation in Indian forensic contexts. The pipeline accepts a VCF file of SNP genotypes as input and produces a probabilistic 2D facial composite annotated with confidence intervals. The work addresses a significant gap in forensic genomics: existing phenotyping tools (notably HIrisPlex-S) were trained predominantly on European cohorts and show reduced accuracy when applied to South Asian individuals. Access to the IndiGenomes dataset would allow us to:

1. Derive Indian-population-specific allele frequencies to improve pigmentation prediction priors under a Bayesian correction framework.
2. Construct a reference panel for ancestry inference via PCA and a Random Forest classifier, enabling the pipeline to stratify subjects by sub-continental ancestry before phenotype prediction.
3. Validate polygenic score models for facial morphology traits against a population-representative Indian reference distribution.
